# AI-Generated Website Testing Lab

SiteCheck Studio is an AI-assisted website QA dashboard. It runs live URL/HTML/header checks and presents simulated browser-rendering and AI review results transparently as demo execution.

## Development

Requires Node.js 20+ and npm.

```bash
npm install
npm run dev
npm run test
npm run build
```

## Current scope

- Test profiles: smoke, accessibility, responsive, performance, SEO, comprehensive
- Dashboard overview, test creation, history, run report, and settings
- Suite management planned/in progress
- Browser rendering and AI review are simulated until providers are configured

Built with React, TypeScript, TanStack Start/Router, Tailwind CSS, and Supabase.
